# CSS and Frontend Assets

## First-party assets

Page-specific JavaScript and CSS sources live in `app/assets/js/`,
`app/assets/css/`, and `app/admin/assets/`. Edit the source files. Do not edit
their generated `.min.js` or `.min.css` files.

Run the build after you change a source file:

```bash
npm run build
```

The build script minifies the configured first-party assets. It also builds
frontend dependencies into `usersc/js/` and `usersc/css/`. Those directories
are ignored by Git and are recreated during deployment. Do not commit their
generated files. See [ADR-018](adr/ADR-018-build-at-deploy-for-frontend-vendoring.md).

## UserSpice child theme

The `elanregistry` child theme uses
`usersc/templates/customizer/assets/child_themes/elanregistry.php` for its
Customizer configuration. The generated stylesheet is versioned by timestamp
in the same directory, for example
`elanregistry-20260504123354.css`. This stylesheet is generated by UserSpice's
Customizer; `npm run build` does not generate it.

To change child-theme settings or CSS, use the Customizer in the UserSpice
admin interface. Do not create or edit a `consolidated.css` file. That file is
not part of the current child-theme layout.

## Frontend dependencies

Project frontend dependencies are declared in `package.json` and built by
`scripts/build.js`. The deployed files include MapLibre GL, VersaTiles styles,
Chart.js, DataTables, and FilePond assets. The build also minifies the
first-party sources described above.

UserSpice supplies its own framework assets, including Bootstrap and jQuery.
Their exact versions can change when UserSpice is updated. Check the installed
files and the current UserSpice documentation before relying on a version.

## Checklist

- Edit first-party source files, not generated minified files.
- Run `npm run build` after a source or dependency change.
- Do not commit generated files under `usersc/js/` or `usersc/css/`.
- Use the UserSpice Customizer to change the child theme.
- Review [UI_STANDARDS.md](UI_STANDARDS.md) before a user-interface change.
