# v2.30.2–v2.30.6 Combined Deploy Sheet

This is one committed document, not a per-milestone gitignored draft. Rationale
(decided during `/finish-milestone v2.30.3`): test.elanregistry.org gets an
incremental deploy as each of v2.30.2 through v2.30.6 finishes gating; prod
gets exactly **one** deploy, only after v2.30.6 is fully validated on test,
carrying the combined functionality of v2.30.2–v2.30.6. Each milestone appends
its own TEST section below as it finishes `/finish-milestone`. The PROD section
is added once, at v2.30.6's turn, and covers the full range in one push.

Order per milestone: PRE-DEPLOY → TEST → VALIDATE TEST. Do not deploy the next
milestone's TEST section until the previous one's VALIDATE TEST is fully
ticked. Do not start PROD (bottom of this file) until v2.30.6's VALIDATE TEST
is fully ticked.

**Deployment hosts**: see `.claude.local.md` § "Deployment hosts" for the ssh
host alias and docroots — not reproduced here since this file is committed
to a public repo.
